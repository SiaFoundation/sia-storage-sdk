# `connectPreAuthorized` now takes a `PreAuthorizedKey` instead of a raw seed

The builder's pre-authorized connect method used to take the 32-byte private key
seed as raw bytes. It now takes a `PreAuthorizedKey`, so the seed is validated
once when the key is created rather than on every connect. Callers holding a
stored seed should import it first: `PreAuthorizedKey.from_seed(seed)` in Python,
`PreAuthorizedKey(seed:)` in Swift, and `PreAuthorizedKey.fromSeed(seed)` in
Kotlin.
